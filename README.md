# Smart License Downloader (Chrome/Edge Extension) — v1.1

## ฟีเจอร์
- เลือกเดือน/ปีจาก dropdown (ปี fix ไว้ 2020-2030, default = ปีปัจจุบันของเครื่องอัตโนมัติ)
- เลือก **รูปแบบวันที่บนหน้าเว็บ** ได้ 5 แบบ (ดูตารางด้านล่าง) — ค่าเริ่มต้นคือ `DD Mon YYYY` (เช่น `04 Aug 2026`)
- **เปลี่ยนหน้าอัตโนมัติ** — ถ้าหน้าปัจจุบันแสดงไม่ครบจำนวนที่ต้องการ จะกดปุ่ม "Next Page" ให้เองจนกว่าจะครบ หรือหมดหน้า หรือเจอเดือนที่เก่ากว่าที่ต้องการ (ปิดได้จากช่องติ๊ก)
- จำกัดจำนวนหน้าสูงสุดที่จะข้าม (กันกรณี selector หาปุ่มไม่เจอแล้ววนลูปค้าง)
- ใส่ CSS selector ของปุ่ม Next เองได้ ถ้า auto-detect หาไม่เจอ
- ปรับ min/max wait ได้จาก popup
- Log แบบ real-time ในหน้า popup
- ประวัติดาวน์โหลดแยกตามโดเมน เก็บด้วย `chrome.storage.local` (กันโหลดซ้ำ) + ปุ่มล้างประวัติ

## รูปแบบวันที่ที่รองรับ

| ค่าที่เลือก | ตัวอย่าง | พบบ่อยแค่ไหน |
|---|---|---|
| `DD Mon YYYY` (default) | `04 Aug 2026` / `04 August 2026` | บ่อยที่สุดในเว็บ marketplace สไตล์นี้ (ตรงกับ Freepik/Magnific ที่ใช้อยู่) |
| `Mon DD, YYYY` | `Aug 04, 2026` / `August 04, 2026` | พบบ่อยในเว็บสไตล์ US SaaS |
| `YYYY-MM-DD` | `2026-08-04` | พบในเว็บ/ระบบที่เน้น technical, export ข้อมูล |
| `DD/MM/YYYY` | `04/08/2026` | ตัวเลขล้วน สไตล์ยุโรป/ไทย |
| `MM/DD/YYYY` | `08/04/2026` | ตัวเลขล้วน สไตล์อเมริกา |

ระบบจะ**อ่านวันที่จากแต่ละแถวจริง แล้วเทียบเฉพาะเดือน+ปี** (ไม่สนวันที่) จึงดึงได้ครบทุกรายการในเดือนนั้น โดยไม่ต้องพิมพ์คำค้นเอง

## การเปลี่ยนหน้าอัตโนมัติ ทำงานอย่างไร
1. สแกนแถวทั้งหมดในหน้าปัจจุบัน ดาวน์โหลดรายการที่ตรงเดือน/ปีที่ยังไม่เคยโหลด
2. ถ้ายังไม่ครบจำนวนที่ตั้งไว้ จะหาปุ่ม "Next Page" ให้อัตโนมัติ (ค้นจากข้อความ "Next Page", "Next", ">" หรือ `aria-label`)
3. คลิกปุ่ม แล้ว**รอจน DOM ของตารางเปลี่ยนจริง** (ไม่ใช่รอเวลาคงที่) ก่อนสแกนหน้าใหม่
4. หยุดอัตโนมัติเมื่อ: ครบจำนวน / ปุ่ม Next หายไปหรือกดไม่ได้แล้ว (ปิด/หน้าสุดท้าย) / เจอว่าทุกแถวในหน้านั้นเก่ากว่าเดือนที่ต้องการแล้ว (แปลว่าผ่านช่วงที่ต้องการมาแล้ว) / ถึงจำนวนหน้าสูงสุดที่ตั้งไว้

**ถ้า auto-detect หาปุ่ม Next ไม่เจอ:** คลิกขวาที่ปุ่ม Next Page บนเว็บนั้น → Inspect → ในแผง Elements คลิกขวาที่ tag ที่ไฮไลต์ → Copy → Copy selector → เอามาวางในช่อง "CSS selector ปุ่ม Next" ในส่วนตั้งค่าขั้นสูงของ popup

**ข้อจำกัด:** ฟีเจอร์นี้ออกแบบมาสำหรับเว็บที่เปลี่ยนหน้าแบบ AJAX/SPA (URL ไม่เปลี่ยน, เนื้อหาโหลดใหม่ในหน้าเดิม) ซึ่งเป็นรูปแบบที่พบในภาพตัวอย่างที่ให้มา ถ้าเว็บไหนกด Next แล้ว browser โหลดหน้าใหม่ทั้งหน้า (URL เปลี่ยนเป็น `?page=2`) สคริปต์ปัจจุบันจะหยุดทำงานตรงนั้น (เพราะ context ของสคริปต์ที่ inject ไว้จะถูกทำลายไปพร้อมกับหน้าเดิม) — ถ้าเจอเคสนี้แจ้งมาได้ จะปรับให้เป็น content script ที่ทำงานข้ามการโหลดหน้าแทน

## วิธีติดตั้งแบบทดสอบ (Load unpacked)
1. เปิด `chrome://extensions` (หรือ `edge://extensions` บน Edge)
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้ (ที่มี `manifest.json`)
4. ปักหมุดไอคอนไว้ที่ toolbar

## วิธีใช้งาน
1. เปิดหน้าเว็บที่มีตารางรายการ license
2. กดไอคอนส่วนขยาย
3. เลือกเดือน/ปี, รูปแบบวันที่ (ถ้าไม่ใช่แบบ default), จำนวนที่ต้องการ
4. ตรวจสอบว่า "ไปหน้าถัดไปอัตโนมัติ" ติ๊กอยู่ (ถ้าต้องการ) แล้วกด **เริ่มดาวน์โหลด**
5. ดู log ความคืบหน้าได้ในหน้า popup

### ข้อควรระวังเรื่อง
- การจำลองคลิกอัตโนมัติบนเว็บของบุคคลที่สาม อาจขัดกับ Terms of Service ของเว็บนั้น — ใช้เพื่อดาวน์โหลดสิทธิ์ที่ตนเองมีอยู่แล้วเท่านั้น
