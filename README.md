# Smart License Downloader (Chrome/Edge Extension) — v1.1

## ฟีเจอร์
- เลือกเดือน/ปีจาก dropdown (ปี fix ไว้ 2020-2030, default = ปีปัจจุบันของเครื่องอัตโนมัติ)
- เลือก **รูปแบบวันที่บนหน้าเว็บ** ได้ 5 แบบ (ดูตารางด้านล่าง) — ค่าเริ่มต้นคือ `DD Mon YYYY` (เช่น `04 Aug 2026`)
- **เปลี่ยนหน้าอัตโนมัติ** — ถ้าหน้าปัจจุบันแสดงไม่ครบจำนวนที่ต้องการ จะกดปุ่ม "Next Page" ให้เองจนกว่าจะครบ หรือหมดหน้า หรือเจอเดือนที่เก่ากว่าที่ต้องการ (ปิดได้จากช่องติ๊ก)
- จำกัดจำนวนหน้าสูงสุดที่จะข้าม (กันกรณี selector หาปุ่มไม่เจอแล้ววนลูปค้าง)
- ใส่ CSS selector ของปุ่ม Next เองได้ ถ้า auto-detect หาไม่เจอ
- ปรับ min/max wait ได้จาก popup
- Log แบบ real-time ในหน้า popup
- ประวัติดาวน์โหลด

## วิธีติดตั้งแบบทดสอบ (Load unpacked)
1. เปิด `chrome://extensions` (หรือ `edge://extensions` บน Edge)
2. เปิด **Developer mode** (มุมขวาบน)
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้
4. ปักหมุดไอคอนไว้ที่ toolbar

## วิธีใช้งาน
1. เปิดหน้าเว็บที่มีตารางรายการ license
2. กดไอคอนส่วนขยาย
3. เลือกเดือน/ปี, รูปแบบวันที่ (ถ้าไม่ใช่แบบ default), จำนวนที่ต้องการ
4. ตรวจสอบว่า "ไปหน้าถัดไปอัตโนมัติ" ติ๊กอยู่ (ถ้าต้องการ) แล้วกด **เริ่มดาวน์โหลด**
5. ดู log ความคืบหน้าได้ในหน้า popup

### ข้อควรระวังเรื่อง
- การจำลองคลิกอัตโนมัติบนเว็บของบุคคลที่สาม อาจขัดกับ Terms of Service ของเว็บนั้น — ใช้เพื่อดาวน์โหลดสิทธิ์ที่ตนเองมีอยู่แล้วเท่านั้น
